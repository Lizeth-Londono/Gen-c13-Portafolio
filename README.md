## 📖 Descripción

Este repositorio documenta la planeación, el proceso creativo, los bocetos, los wireframes, las exploraciones visuales y el futuro desarrollo de mi portafolio profesional.

La propuesta se construye alrededor de la identidad:

```text
LXL
CODE x LIHEN
LIZETH LONDOÑO
````

Con este concepto quiero conectar dos partes importantes de mi perfil:

* Mi formación como **Full-Stack Developer Jr.**
* Mi experiencia como **cofundadora de LIHEN.CO**

El portafolio tendrá como propósito presentar de forma clara y profesional:

* quién soy;
* qué estoy aprendiendo;
* cuáles son mis habilidades;
* qué proyectos he desarrollado;
* cuál fue mi participación en cada proyecto;
* cómo ha sido mi proceso de crecimiento;
* cómo pueden contactarme.

La propuesta se encuentra actualmente en etapa de diseño y puede cambiar después de recibir retroalimentación.

---

## 🎯 Objetivo

Mi objetivo es desarrollar un portafolio que muestre evidencia real de mis conocimientos y de mi evolución como desarrolladora.

No quiero presentar únicamente una lista de tecnologías. En cada proyecto quiero explicar:

* qué problema se buscó resolver;
* cuál fue mi participación;
* qué decisiones tomé;
* qué tecnologías utilicé;
* qué dificultades encontré;
* cómo se abordaron;
* qué aprendí durante el proceso;
* dónde se puede consultar el código;
* dónde se puede ver el proyecto funcionando, cuando exista una demostración.

El portafolio estará dirigido principalmente a:

* reclutadores;
* empresas de tecnología;
* líderes técnicos;
* posibles clientes;
* docentes;
* compañeros del bootcamp;
* personas interesadas en conocer mi trabajo.

Por esta razón, el sitio deberá ser:

* fácil de navegar;
* profesional;
* responsive;
* visualmente coherente;
* accesible;
* directo;
* actualizado;
* comprensible incluso para personas no técnicas.

* números;

## ✨ Introducción animada propuesta

Antes de mostrar la página de inicio, quiero explorar una introducción visual corta.

La idea es comenzar con una pantalla oscura en la que aparezcan caracteres distribuidos de forma irregular.

### Caracteres considerados propuesta

```text
0  1  3  5  8
<  >  =
{  }  ;
#  %
/  //
?  &
L  X
```

Los caracteres utilizarían principalmente estos colores:

* morado;
* turquesa;
* blanco;
* gris oscuro.

Después, los símbolos se desplazarían y reorganizarían para formar:

```text
LXL
```

Posteriormente aparecería la identidad:

```text
LXL
CODE x LIHEN
LIZETH LONDOÑO
```

Finalmente, la animación daría paso a la pantalla principal.

### Significado propuesta

La introducción busca representar cómo diferentes elementos pueden organizarse hasta convertirse en una identidad y una solución digital:

```text
Ideas dispersas
        ↓
Conocimientos y experiencias
        ↓
Organización
        ↓
LXL
        ↓
Soluciones digitales reales
```

La introducción no será únicamente decorativa. Tendrá relación con el concepto general del portafolio.

### Alcance inicial propuesta

La introducción todavía es una intención de diseño.

Las posibles alternativas de implementación son:

* prototipo mediante Smart Animate en Figma;
* animación mediante CSS;
* animación mediante JavaScript;
* versión simplificada si la propuesta completa supera el alcance actual.

La prioridad será siempre que el portafolio sea funcional, responsive, accesible y fácil de navegar.

Las imágenes generadas con IA no representan:
